# Rise and Fall Remaster

Неофициальный ремастер-патч для игры Rise and Fall: Civilization at War.

Проверено с русской версией игры 1.15. Другие языковые версии 1.15 могут работать, если у них тот же exe-файл игры. Установщик сначала проверяет это и сообщит, если ваша версия не подходит. В этом случае, пожалуйста, откройте issue, чтобы я мог добавить вашу версию.

На нерусской версии игры новые тексты (кооперативные карты, меню) будут на английском.

Что менялось в каждой версии, смотрите в [списке изменений](CHANGELOG.md) (на английском).

## Что нового

### 🖥️ Графика и экран

- Полноэкранный режим без рамки в разрешении рабочего стола
- Плавная прокрутка камеры и большее отдаление (ползунок в Настройки > Интерфейс)
- Ультра-настройки графики, полные mipmap-уровни и новые шейдеры для юнитов, земли и воды
- HD-текстуры по желанию, они масштабируются на вашей видеокарте
- DXVK (Direct3D 9 через Vulkan) на видеокартах, которые его поддерживают

### ⚔️ Геймплей и ИИ

- Более сильный «Сложный» ИИ со своим характером у каждой цивилизации
- Умнее ведут себя артиллерия и транспорты
- Умнее выбирают цели лучники: стрелковые юниты бьют сначала осадные машины, потом лучников, потом героев. Стойка охраны работает как режим против осады
- ИИ атакует вместе со своими союзниками-ИИ и выбирает цели по задуманным весам
- ИИ отправляет корабли только с войсками на борту и раньше начинает использовать паромы
- Триггеры сценариев считают долг долгом: на Гавгамелах компьютеры больше не получают бесконечное бесплатное золото
- Лучников и копейщиков можно нанимать в казармах и стрельбищах других цивилизаций
- Лимит юнитов поднят до 10000

### 🏰 Кооператив и карты

- «Выживание»: бесконечный режим с осадными волнами и тремя уровнями сложности
- Boss Hunt, Co-op Roles и Co-op vs Hard AI
- Исправления Co-op Roles: общий лимит населения, статуи славы у командира, сильный старт у экономиста

### 🌐 Сетевая игра и установка

- Установщик собирает новую папку игры из ваших файлов. Исходная установка не меняется
- Игра по локальной сети и по IP, а отпечаток защищает от рассинхронизации
- Обновление из лаунчера кнопкой «Обновить сейчас». Установщик на русском, немецком и английском
- Работает и с другими языковыми версиями 1.15, если совпадает exe-файл

### 🔧 Исправления

- Больше нет «мёртвых» кликов мыши сразу после запуска
- Графические настройки, которые вы меняете в игре, сохраняются
- Во время установки больше не мелькают окна консоли

## Установка

Скачайте `RaF-Remaster-Setup.exe` в разделе [Releases](../../releases) и запустите его.

Установщик сам найдёт игру и скопирует её в новую папку. Ваша исходная установка только читается и не меняется.

Всё собирается на вашем компьютере из ваших собственных файлов игры. В установщике нет файлов игры.

После установки появятся ярлыки: играть, создать или подключиться к сетевой игре, удалить.

## Сетевая игра

В конце установщик показывает отпечаток (fingerprint) игровых данных. Он также записан в файле `REMASTER.txt` в папке игры.

У всех игроков отпечаток должен совпадать. Если он разный, игра рассинхронизируется.

Для игры по локальной сети или по IP используйте ярлыки «Создать сетевую игру» и «Присоединиться к сетевой игре».

## Кооперативные карты

Ремастер добавляет карты, на которых вы играете вместе против компьютера:

- **Выживание** (легко, средне, сложно): волны идут, пока вы не падёте, с таранами и катапультами, так что одни стены не спасут
- **Boss Hunt**: охота на героев, этап за этапом
- **Co-op Roles**: один игрок ведёт экономику, второй командует армией
- **Co-op vs Hard AI**: два игрока против трёх компьютерных противников

Их можно выбрать в лобби схватки или сетевой игры, как любую другую карту.

В Co-op Roles лимит населения командира следует за лимитом экономиста (амбар, рынок, алтарь и так далее), а готовые статуи славы достаются командиру. Экономист начинает с героем 10-го уровня и неограниченной славой, чтобы нанять всех советников. Если два игрока выбрали разные цивилизации, появится предупреждение, так что играйте за одну и ту же.

## Умный выбор целей у лучников

Стрелковые юниты выбирают цели в таком порядке: осадные машины, потом лучники, потом герои. Цели в зоне досягаемости они не оставляют. Функция называется «target-priority» и включена по умолчанию.

Стойка охраны работает как режим против осады: осадные машины в зоне досягаемости всегда бьются первыми. Подходит для защитников стен.

## Linux и Steam Deck

Не проверялось. Игра и установщик написаны для Windows, поэтому пробовать стоит через Proton или Wine.

Если у вас получилось, напишите, пожалуйста, в issue, как именно.

## Проблемы

Установщик пишет журнал в `%TEMP%\RaF-Remaster-Setup.log`. Пожалуйста, приложите его, когда открываете issue.

Чтобы удалить ремастер, используйте ярлык удаления. Исходная игра остаётся без изменений.

## Сборка из исходников

Нужны Windows, [uv](https://docs.astral.sh/uv/) и Python 3.14 с python.org.

Другие сборки Python сжимают файлы карт немного иначе. Игра будет работать, но отпечаток не совпадёт с другими игроками.

```
python tools/build_installer.py
```

Скрипт скачает нужные сторонние программы фиксированных версий, проверит их хеши и создаст `dist/RaF-Remaster-Setup.exe`.

Для офлайн-тестов нужны ещё несколько пакетов Python:

```
python -m pip install unicorn capstone pefile numpy pillow fonttools
python tools/run_stub_tests.py
```
