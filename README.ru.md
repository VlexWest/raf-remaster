# Rise and Fall Remaster

Неофициальный ремастер-патч для игры Rise and Fall: Civilization at War.

Поддерживается русская версия игры 1.15. Другие версии пока не поддерживаются.

## Что нового

- Полноэкранный режим без рамки в разрешении рабочего стола
- Плавная прокрутка камеры и большее отдаление (ползунок в Настройки > Интерфейс)
- Ультра-настройки графики, полные mipmap-уровни и новые шейдеры для юнитов, земли и воды
- HD-текстуры по желанию, они масштабируются на вашей видеокарте
- DXVK (Direct3D 9 через Vulkan) на видеокартах, которые его поддерживают
- Более сильный «Сложный» ИИ со своим характером у каждой цивилизации
- Умнее ведут себя артиллерия и транспорты
- Лимит юнитов поднят до 10000
- Новые кооперативные карты, в том числе режим «Выживание»
- Исправлены «мёртвые» клики мыши сразу после запуска

## Установка

Скачайте `RaF-Remaster-Setup.exe` в разделе [Releases](../../releases) и запустите его.

Установщик сам найдёт игру и скопирует её в новую папку. Ваша исходная установка только читается и не меняется.

Всё собирается на вашем компьютере из ваших собственных файлов игры. В установщике нет файлов игры.

После установки появятся ярлыки: играть, создать или подключиться к сетевой игре, удалить.

## Сетевая игра

В конце установщик показывает отпечаток (fingerprint) игровых данных. Он также записан в файле `REMASTER.txt` в папке игры.

У всех игроков отпечаток должен совпадать. Если он разный, игра рассинхронизируется.

Для игры по локальной сети или по IP используйте ярлыки «Создать сетевую игру» и «Присоединиться к сетевой игре».

## Кооперативные карты

Ремастер добавляет карты, на которых вы играете вместе против компьютера:

- **Survival**: продержаться против волн врагов, есть версия с зомби
- **Survival Endless**: волны идут, пока вы не падёте
- **Boss Hunt**: охота на героев, этап за этапом
- **Co-op Roles**: один игрок ведёт экономику, второй командует армией
- **Co-op vs Hard AI**: два игрока против трёх компьютерных противников

Их можно выбрать в лобби схватки или сетевой игры, как любую другую карту.

## Linux и Steam Deck

Не проверялось. Игра и установщик написаны для Windows, поэтому пробовать стоит через Proton или Wine.

Если у вас получилось, напишите, пожалуйста, в issue, как именно.

## Сборка из исходников

Нужны Windows, [uv](https://docs.astral.sh/uv/) и Python 3.14 с python.org.

Другие сборки Python сжимают файлы карт немного иначе. Игра будет работать, но отпечаток не совпадёт с другими игроками.

```
python tools/build_installer.py
```

Скрипт скачает нужные сторонние программы фиксированных версий, проверит их хеши и создаст `dist/RaF-Remaster-Setup.exe`.
